# Архіватор

[← Документація](../README.md)

Файл: `Archive.java` (~640 рядків) — чиста Java без Android, тести в `test/ArchiveTest.java` (74 перевірки).

## Формати

| Вид | Розширення | Перегляд | Розпакування | Створення |
|---|---|:-:|:-:|:-:|
| `zip` | zip, jar, apk, apks, xapk, apkm, aar, docx, xlsx, pptx, odt, ods, odp, epub, cbz, xpi, ipa, war, kmz, 3mf | ✓ | ✓ | ✓ (zip) |
| `tgz` | tar.gz, tgz | ✓ | ✓ | ✓ |
| `tar` | tar | ✓ | ✓ | ✓ |
| `gz` | gz (один файл) | ✓ | ✓ | ✓ (`gzip`) |

## Перегляд

`list(file, charset)` повертає записи `{name, size, csize, mtime, dir}`.

- **ZIP** — центральний каталог через `java.util.zip.ZipFile`. Кодування назв: якщо не задано, `zipCharset` пробує UTF-8, а коли Java відкидає назви — CP866 (так пишуть кирилицю старі архіватори Windows без прапорця UTF-8). У інтерфейсі можна вибрати й інше.
- **Пароль** — `zipEncrypted` дивиться біт 0 прапорців першого локального заголовка й кидає `Encrypted`, щоб показати зрозуміле повідомлення замість помилки розпаковування.
- **TAR** — власний читач `TarIn`: заголовки ustar з префіксом, GNU LongLink (`L`) для довгих назв, PAX (`x`) з ключем `path` (глобальні `g` пропускаються), розміри у вісімковій формі й base-256 (понад 8 ГБ). Для `.tar.gz` дані йдуть через `GZIPInputStream`.
- **GZ** — назва без `.gz`, розмір — з останніх 4 байтів (ISIZE).

## Розпакування

`extract(archive, dest, only, charset, conflict, progress)`:

- `only` — набір записів (файли або папки з `/` у кінці); `null` — усе. Вибрані папки розпаковуються **без батьківських папок архіву**: вибравши `Проєкт/дані/`, отримаєте `dest/дані/…`.
- `conflict` — `rename`, `replace`, `skip`.
- **Zip slip** — провідні `/` і `./` прибираються, а запис, канонічний шлях якого виходить за межі `dest` (`../../…`, посилання), пропускається.
- Прогрес — за розпакованими байтами; `Progress.tick` повертає `false` → `Cancelled`, а недописаний файл видаляється.
- Порожні папки відтворюються; час зміни файлів — з архіву.

## Створення

- `zip(sources, out, level, progress)` — `ZipOutputStream` з UTF-8 назвами (прапорець EFS), рівні 0–9; порожні папки зберігаються записами `папка/`.
- `tar(sources, out, gzip, progress)` — власний `TarOut`: ustar, GNU LongLink для назв понад 100 байтів, base-256 для файлів понад 8 ГБ, вирівнювання блоків 512 байтів і два порожні блоки в кінці.
- `gzip(src, out, progress)`.
- Сам архів, якщо він лежить усередині папки, що стискається, пропускається.

## Тести

`test/ArchiveTest.java`: імена й унікальні назви; для ZIP, TAR і TAR.GZ — довгі кириличні назви, вкладені папки, порожня папка, 300 КБ випадкових даних, повторне розпакування з `rename`, `skip`, розпакування підпапки, скасування з прибиранням; GZ; ZIP з назвами в CP866; zip slip (`../../`); прапорець шифрування.
