# Файли й завдання

[← Документація](../README.md)

Файли: `Fs.java`, `Ops.java`, `Names.java`, `Store.java`, `Encodings.java`.

## Fs — сховища і папки

- **Сховища** — `StorageManager.getStorageVolumes()`; шлях — `getDirectory()` на Android 11+ або прихованим `getPathFile()` / `getPath()` раніше. Назви: «Внутрішня пам’ять», опис від системи для SD-карти (або «SD-карта» / «Сховище»). Для кожного — загальний і вільний об’єм.
- **Вміст папки** — `java.io.File` (з дозволом «Доступ до всіх файлів» це найшвидший шлях). Для папки — кількість елементів, для файлу — розмір; кошик `.teka_trash` не показується. Помилки: `missing`, `notdir`, `access`.
- **Створення й перейменування** перевіряють назву (`Names.invalid`: порожня, `/ \ : * ? " < > |`, керівні символи, `.` і `..`) і збіг. Зміна лише регістру на FAT/exFAT іде через тимчасову назву.
- **Категорії** — запит до `MediaStore.Files` зовнішньої медіатеки: фото, відео, аудіо за `MEDIA_TYPE`; документи, архіви, APK — за розширенням; «нещодавні» — змінені за 30 днів; «великі» — понад 50 МБ, від найбільших. Приховані шляхи (`/.`) пропускаються. `categoryStats` рахує кількість і обсяг для екрана «Огляд».

## Ops — завдання з прогресом

Пул із трьох потоків. Кожне завдання — `Ops.Job` з `id`, видом і параметрами JSON. Прогрес (`done/total` у байтах або кроках, `files/filesTotal`, поточна назва) надсилається не частіше ніж раз на 200 мс; скасування перевіряється між блоками по 256 КБ. Після завершення всі змінені шляхи передаються `MediaScannerConnection`, щоб галерея й музичні застосунки побачили зміни.

| Вид | Що робить |
|---|---|
| `copy`, `move` | Збіг назв: `rename` (додає «(1)»), `replace`, `skip`; папки зливаються. Переміщення в межах сховища — `renameTo` (миттєво), між сховищами — копія + видалення. Вставка в ту саму папку — копія з новою назвою. Папку не можна вставити саму в себе. Недописаний файл при скасуванні видаляється |
| `delete` | Рекурсивно, з лічильником файлів |
| `trash`, `restore`, `purge`, `trashClean`, `trashList` | Кошик: див. нижче |
| `size` | Розмір, кількість файлів і папок |
| `search` | Обхід у глибину; частина назви або шаблон `*`/`?`; фільтр за типом; пошук у тексті файлів до 2 МБ з визначенням кодування. Знайдене надходить порціями кожні 300 мс, до 1000 результатів |
| `hash` | MD5, SHA-1, SHA-256 за один прохід |
| `analyze` | Розмір кожного елемента кореня, розподіл за типами (кошик окремо), 50 найбільших файлів (купа з мінімумом), об’єм і вільне місце |
| `zip`, `tar`, `tgz`, `extract` | Через [`Archive`](archive.md) |
| `convert` | Через [`Convert`](convert.md) |
| `renameMany` | Двофазне перейменування: спершу всі в тимчасові назви, потім у кінцеві — так працює обмін назвами a ↔ b; збіги з наявними файлами отримують «(1)» |
| `stats`, `apps`, `apkBackup`, `installBundle` | Категорії для «Огляду», [застосунки](pc.md) |

Помилки перекладаються людською мовою: `ENOSPC` → «Немає вільного місця», `EACCES`/`EPERM` → «Немає доступу», брак пам’яті, архів з паролем.

### Кошик

- Файл переноситься в `<корінь сховища>/.teka_trash/<час>_<назва>` (`renameTo`, тож навіть гігабайти — миттєво; якщо не вдається — копія й видалення). Поруч `.nomedia`, щоб галерея не показувала вміст.
- `.index.json` у кошику зберігає вихідний шлях, час, тип і розмір; запис іде через тимчасовий файл.
- `restore` повертає на місце, створюючи батьківські папки; при збігу — «(1)».
- `trashClean` під час запуску видаляє записи, старші за N днів, і записи без файлів.

## Names

Чиста Java, з тестами: `split` (враховує `.tar.gz`, `.tar.bz2`, `.tar.xz`; у `.bashrc` розширення немає), `ext`, `unique` («звіт.pdf» → «звіт (1).pdf», «звіт (1).pdf» → «звіт (2).pdf»), `invalid`, `inside` (канонічні шляхи — захист від `..` і посилань), `human` («1,5 КБ»).

## Store, Encodings

`Store` — ключ-значення у внутрішній пам’яті (налаштування інтерфейсу). `Encodings` — визначення й перетворення кодувань (UTF-8 з BOM і без, UTF-16, Windows-1251, KOI8-U/R, CP866, ISO-8859-x, азійські) і кінців рядків; спільний з редактором «Код». Використовується для текстового переглядача, пошуку в тексті й зміни кодування.
