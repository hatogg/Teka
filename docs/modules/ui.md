# Інтерфейс

[← Документація](../README.md)

Файли: `app/assets/www/index.html`, `css/app.css` і 14 модулів у `js/` (~3900 рядків разом), без фреймворків і сторонніх бібліотек. Скрипти підключаються звичайними `<script>` у порядку залежностей; `mock.js` — лише в браузері без Android-моста.

| Модуль | Що в ньому |
|---|---|
| `icons.js` | ~120 лінійних іконок 24×24 (`ic(name)`) |
| `ui.js` | `h()` для DOM, стек шарів (аркуші, діалоги, сторінки) з кнопкою «Назад», меню, вибір зі списку, `prompt`/`confirm`, сповіщення з дією |
| `native.js` | Обгортка моста: синхронні виклики, `call()` → Promise, `task()` → `{id, promise, cancel}` з подіями прогресу; адреси `/f`, `/t`, `/pdf`, `/app` |
| `core.js` | Налаштування, формати розмірів і дат, типи файлів і їхні кольори, значки й мініатюри, рядок списку з довгим дотиком, поступове домальовування довгих списків, **картки завдань** з прогресом і скасуванням, дрібні елементи форм |
| `browser.js` | Вкладка «Файли»: хлібні крихти, сортування, список/сітка для кожної папки, приховані, вибір, панель дій, меню файлу й папки, історія «Назад», **буфер обміну** («Вставити» з вибором при збігу назв), закладки |
| `ops.js` | Нова папка/файл, перейменування, **зміна розширення** з підказкою конвертувати, видалення в кошик, **стиснення** і **розпакування**, властивості з хешами, **групове перейменування** з переглядом |
| `picker.js` | Вибір папки (куди розпакувати, зберегти) і вибір файлів для конвертера — з папок або з усіх фото / відео / музики |
| `viewers.js` | Відкриття за типом; галерея (3 слайди, гортання, щипок, подвійний дотик), відео, музика з чергою, текст із кодуваннями й редагуванням, PDF з лінивими сторінками, APK |
| `archive.js` | Перегляд архіву: дерево з плоского списку записів, розміри папок, стиснення, вибір, відкриття файлу з архіву, кодування назв |
| `convert.js` | Які перетворення доступні для вибраних файлів, підказка для зміни розширення, аркуш параметрів, сторінка «Конвертер» |
| `tools.js` | Вкладка «Інструменти», кошик, аналіз (SVG-кільце, смуги), застосунки, доступ з ПК, пошук з результатами наживо, налаштування |
| `home.js` | Вкладка «Огляд»: сховища, категорії з обсягами, швидкі папки й закладки, нещодавні; сторінки категорій |
| `main.js` | Запуск, вкладки, тема, «Назад», обробники подій від Android (`window.__teka`) |
| `mock.js` | Імітація моста з віртуальною файловою системою (дві пам’яті, камера, завантаження, документи, музика, SD-карта), архівом, застосунками й завданнями з прогресом — для розробки й скриншотів |

## Події від Android

```js
window.__teka = {
  onTask(id, d),     // прогрес і підсумок завдань
  onResult(id, d),   // відповіді на Android.call
  onPc(status),      // доступ з ПК увімкнено/вимкнено, події
  onInstall(d),      // підсумок встановлення набору APK
  onPerm(p), resume(p), pause(), config(night),
  onIntent(), onNotif(), toast(text),
  back(),            // → 'ok' | 'exit'
};
```

## Вигляд

- Дві теми з тими самими токенами (`--bg`, `--panel`, `--raised`, `--text`, `--muted`, `--accent` #F4B740…), тема системи або вибрана вручну; кольори рядка стану синхронізуються з Android.
- Кожен тип файлу має свій колір (`--k-image`, `--k-video`, `--k-archive`…) для значків, категорій і діаграм.
- Папки — заповнені бурштинові значки; для документів, тексту й архівів на значку видно розширення.
- Нижня навігація з трьох вкладок; у режимі вибору її заміняє панель дій. Картки завдань і буфер обміну — над навігацією; поверх відкритих сторінок картки завдань теж видно.
- Довгий дотик — і власний таймер 480 мс, і подія `contextmenu` (миша); клік одразу після довгого дотику ігнорується.
- Списки на тисячі файлів домальовуються порціями по 120 через `IntersectionObserver`; мініатюри — `loading="lazy"`.
